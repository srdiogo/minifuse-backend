# Distribution packages

[MiniFuse Control](https://github.com/srdiogo/minifuse-control/releases) publishes
the full desktop distribution with the backend and driver included.
See its [native package installation guide](https://github.com/srdiogo/minifuse-control/blob/main/docs/NATIVE_PACKAGES.md).

For standalone backend builds and client integration, see
[backend installation](INSTALL.md) and the [session API](IPC.md).
